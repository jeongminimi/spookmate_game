# SPOOKMATE

동거 요괴가 설거지하는 걸 펫캠으로 지켜보며 **주의**와 **칭찬** 두 버튼으로 관리하는 블랙코미디 웹게임.

요괴는 실시간 3D다. 모델 파일도 텍스처도 없다. 도형을 수식(SDF)으로 정의하고 프래그먼트 셰이더에서
레이마칭으로 그린다. 그림자, 음영, 가장자리 빛이 전부 실제 계산 결과다.

## 플레이 방법

`index.html`을 브라우저로 열면 끝이다. 빌드도 서버도 의존성도 없다.

1. 같이 살 요괴를 고른다 (오이와 · 야차)
2. 요괴가 혼자 설거지한다. 가끔 딴짓하고 가끔 풀이 죽는다
3. 사고 치기 직전에 **전조**가 뜬다
   - 🔴 **빨간 전조** → `주의`로 막는다
   - 🔵 **파란 전조** → `칭찬`으로 막는다
   - 틀린 버튼을 누르면 그 자리에서 사고가 터진다
4. 사고 3번이면 그날 일은 끝. 닦은 그릇 하나에 토큰 하나

## 요괴

성격이 대사가 아니라 **규칙**이다. 전조 색의 비율이 다르고, 혼냈을 때 반응이 다르다.

| | 오이와 (우울) | 야차 (분노) |
|---|---|---|
| 원형 | 일본 초롱 요괴 | 불교 수호신 야차 |
| 실루엣 | 길고 좁음 | 넓고 다부짐 |
| 설거지 속도 | 느림 (5.0초/개) | 빠름 (3.0초/개) |
| 빨간 전조 비율 | 20% | 80% |
| 혼냈을 때 | 두 배로 가라앉음 (의욕 −22) | 더 열받아 다음 사고가 빨리 옴 (의욕 −11) |
| 폭주 연출 | 초롱 불이 꺼지고 눈물 | 입이 벌어지고 몸에서 열 |

의욕(MOOD)이 낮으면 설거지가 느려지고 **전조 시간도 짧아진다.** 자세도 눈에 띄게 처진다.
0이 되면 파업한다. 칭찬 두 번으로 깨워야 한다.

## 구조

펫캠 화면은 세 겹이다.

```
┌─ 2D canvas  부엌 배경 (벽 · 창 · 상부장)
├─ WebGL      요괴 ← 레이마칭, 투명 배경
└─ 2D canvas  조리대 · 싱크대 · 그릇 · CCTV 표시
```

요괴가 조리대 뒤에 서고 하반신이 가려지는 게 레이어 순서로 자연스럽게 나온다.

```
index.html          배포본 (src를 합친 결과)
build.sh            src → index.html (cat 한 줄)
src/
  a_head.html       CSS
  b_body.html       마크업
  c_shader.js       GLSL — 요괴 두 마리의 SDF와 조명
  d_gl.js           WebGL 셋업
  e_cast.js         요괴 수치와 대사
  f_cam.js          상태기계 (사고 · 의욕 · 전조)
  g_kitchen.js      부엌 2D 레이어
  h_app.js          화면 전환과 메인 루프
preview/            캐릭터 단독 프리뷰 (포즈 전환 · 회전)
archive/            이전 버전들 (2D 선택형 · 2D 펠트 펫캠)
docs/               요괴 제작 현황표
```

소스를 고쳤으면 `./build.sh`로 `index.html`을 다시 만든다.

## 밸런스

봇으로 조건별 3판씩 측정한 결과 (2D 버전 기준, 3D에서 재측정 필요).

| 플레이 | 닦은 그릇 | 걸린 시간 |
|---|---|---|
| 아무것도 안 누름 | 2~5개 | 30초 |
| 전조만 늦게 대응 | 9~15개 | 90~120초 |
| 의욕까지 관리 | 22~25개 | 2분대 |

시간이 갈수록 사고 간격과 전조 시간이 줄어든다. 잘해도 결국 끝난다.
